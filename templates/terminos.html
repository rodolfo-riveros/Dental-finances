Términos de Servicio

Última actualización: 29 de Junio, 2026

1. Aceptación de los Términos

Al acceder y usar DentFinance ("la Aplicación"), aceptas cumplir con estos Términos de Servicio. Si no estás de acuerdo, no uses la Aplicación.

2. Descripción del Servicio

DentFinance es una herramienta de gestión financiera diseñada para clínicas dentales. Permite el registro de gastos, tratamientos, deudas y generación de reportes financieros.

3. Registro de Cuenta

Para usar la Aplicación debes crear una cuenta proporcionando información veraz y actualizada. Eres responsable de mantener la confidencialidad de tus credenciales.

4. Uso Aceptable

Te comprometes a usar la Aplicación únicamente para fines legítimos relacionados con la gestión de tu clínica dental. No debes:

  • Intentar acceder a datos de otros usuarios
  • Usar la Aplicación para actividades ilegales
